# Ferremas - Tienda de Ferretería Online

Proyecto de tienda online para Ferremas, una ferretería que ofrece productos de calidad para el hogar y la construcción.

## Características

- Catálogo de productos con filtros
- Carrito de compras interactivo
- Diseño responsivo
- Interfaz moderna y amigable

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- Git para control de versiones

## Estructura del Proyecto

```
frontend/
├── css/
│   ├── variables.css
│   ├── components.css
│   └── styles.css
├── js/
│   └── main.js
├── img/
├── components/
├── index.html
└── productos.html
```

## Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/ferremas.git
```

2. Abre el archivo `index.html` en tu navegador preferido.

## Uso

- Navega por el catálogo de productos
- Utiliza los filtros para encontrar productos específicos
- Agrega productos al carrito
- Gestiona tu carrito de compras
